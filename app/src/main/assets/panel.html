Claude Code no PC

  1. Copie o comando abaixo e rode no PowerShell deste PC.
  2. Mande uma mensagem no Claude Code, no VS Code ou no terminal. Ao fim da resposta, o uso chega ao celular.

O comando instala um hook em ~/.claude que roda o /usage do Claude Code ao fim das respostas, no máximo a cada 2 minutos e sem gastar tokens. Ele manda só os percentuais e os horários de reset, e guarda um backup dos seus ajustes em settings.json.antes-do-clawdboard.
